# Titanium

Use this reference after detecting an Appcelerator Titanium project.

## Detect

Check:

- Titanium project structure
- `tiapp.xml`
- Appcelerator-specific build files

## Support level

Bugfender does not provide official Titanium support in this setup flow. The known path is the third-party ACA-IT module:

```text
https://github.com/aca-mobile/titanium-bugfender
```

## Recommended behavior

- Be explicit that this is a community-maintained integration path.
- Prefer explanation and repo-specific guidance over blindly editing files.
- If the user wants implementation, inspect the project carefully before changing anything.

## Verification

Point the user to the module’s setup steps and confirm the first log reaches Bugfender after integration.
